## What to build

Allow human conclusions to include uncertainty without hiding it. A partially supported Causal Factor requires a Partial-Support Acknowledgment. A critically challenged Failure Mechanism requires a Critical-Challenge Override addressing each open critical challenge. Unevidenced reviewer beliefs remain labeled Human Assumptions.

Covers PRD user stories 38-41.

## Acceptance criteria

- [ ] Partially supported Causal Factors cannot be finalized without a persisted acknowledgment describing supported and uncertain portions.
- [ ] A critically challenged hypothesis cannot be used as the Failure Mechanism without an override addressing every unresolved critical challenge.
- [ ] Human Assumptions are stored separately and never render as established Causal Factors.
- [ ] Review Surface and exports preserve partial-support qualifications, critical challenges, override rationale, and non-definitive wording.
- [ ] API and browser tests cover required acknowledgments, incomplete overrides, assumption rendering, and successful qualified finalization.
