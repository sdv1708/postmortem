# Deterministic Eval Floor With LLM Judge Framework

The MVP evaluation suite will include deterministic checks for citation integrity, claim support labeling, required sections, timeline ordering, and ambiguity behavior, and it will also establish an LLM-as-judge framework for semantic rubric scoring. LLM judges can assess quality against Ground-Truth Postmortems and scenario expectations, but they must not be the sole validator for citations.

This split keeps the product's trust claims grounded in mechanically verifiable evidence while still creating the experiment framework needed to compare prompts, pipeline stages, and future model choices.
