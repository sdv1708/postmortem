# Incident-Centered Frontend Workflow

The MVP frontend will center on incidents, with nested evidence, analysis run status, and postmortem review workflows. The key routes are incident list, incident creation, incident overview, evidence management, run status, postmortem review, and an internal evaluation dashboard.

Citation clicks in the postmortem review should focus an Evidence Panel with highlighted artifact lines instead of navigating away. The product proof depends on keeping generated claims and source evidence visible in one review context.
