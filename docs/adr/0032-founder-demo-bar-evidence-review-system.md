# Founder Demo Bar: Evidence Review System

The founder-demo bar is that a technical founder should leave believing this is not a postmortem text generator; it is an evidence review system that happens to draft the postmortem. The demo must show a legible async run, multiple plausible hypotheses, exact claim-to-line citations, contradicting evidence, separated unsupported claims, deterministic eval checks, and a defensible architecture story.

The trust bar also includes refusal behavior: when evidence is genuinely insufficient because it is too sparse, too contradictory, or lacks time anchors, the system should say so instead of producing a confident-sounding postmortem. The evaluation suite should include at least one Insufficient Evidence Scenario stub to exercise this mode, even if it is not part of the polished MVP demo path.
