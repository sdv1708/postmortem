# Unsupported Claims Remain Auditable, Not Authoritative

Unsupported and assumption claims should remain visible for review, but they must not be presented as authoritative incident facts in the main postmortem narrative. Supported claims can appear normally, partial claims require caution styling and rationale, and unsupported claims belong in a clearly marked review area.

Markdown exports should distinguish clean final postmortems from review or audit exports. This preserves traceability without allowing unsupported generated content to look like verified incident truth.
