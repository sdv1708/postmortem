# Canonical Ambiguous Deploy Incident Scenario

The MVP's canonical demo scenario is an ambiguous deploy-related API error spike, not a single-obvious-cause outage. Deploy ambiguity best showcases the product's differentiator: multiple ranked RCA hypotheses with supporting and contradicting citations, rather than a system that appears to pattern-match the obvious answer.

The synthetic dataset architecture should support three Incident Scenarios from day one: the deploy scenario as the end-to-end MVP path, plus dependency failure and configuration drift scenarios with evidence files and Ground-Truth Postmortems. This gives the evaluation suite enough variety to reduce prompt overfitting and supports credible demo answers when technical founders ask how the system handles other incident shapes.
